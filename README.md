# 🚀 Object Detection with YOLO

## 📌 Project Overview

This project implements **Object Detection using YOLO (You Only Look Once),
a state-of-the-art deep learning algorithm for real-time object detection. 
The model can identify and locate multiple objects within an image or video by drawing bounding boxes and assigning class labels with confidence scores.

The system is designed to perform fast and accurate object detection,
making it suitable for applications such as surveillance, autonomous vehicles, traffic monitoring, retail analytics, and smart security systems.

---

## 🎯 Features

* Real-time object detection
* Detection of multiple objects in a single frame

## 📂 Project Workflow

1. Load the YOLO model and pre-trained weights.
2. Read input image or video.
3. Preprocess the input data.
4. Run object detection using YOLO.
5. Generate bounding boxes around detected objects.
6. Display class labels and confidence scores.
7. Visualize and save the output.

---

## 🧠 YOLO Architecture

YOLO is a single-stage object detection algorithm that:

* Divides an image into grids.
* Predicts bounding boxes and class probabilities simultaneously.
* Processes the entire image in one forward pass.
* Provides high detection speed with excellent accuracy.
