# YOLOv8 Object Detection and Tracking System

## 📌 Project Overview
This project uses YOLOv8 for real-time object detection and tracking using OpenCV and Streamlit. The system can detect and track objects in videos, webcam, and uploaded media.

## 🚀 Features
- Real-time object detection
- Object tracking using YOLOv8
- Streamlit web application
- Video detection
- Webcam detection
- Image detection

## 🛠️ Technologies Used
- Python
- YOLOv8
- OpenCV
- Streamlit
- NumPy
- Pandas
- PyTorch

## ▶️ How to Run
1. Clone the repository
2. Install requirements
   pip install -r requirements.txt
3. Run the Streamlit app
   streamlit run app.py
